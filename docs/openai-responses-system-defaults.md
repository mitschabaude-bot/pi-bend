# Native Responses defaults

`openai-responses-system-defaults.stream` samples the native millisecond wall clock before initializing provider hooks or preparing the request. `streamWithClock` permits an injected clock, and `streamAt` accepts an explicit timestamp. The factory creates and owns the default SSE diagnostic/abort callbacks. Its producer finalizer retires these callbacks before the caller's finalizer, including early preparation failures.

The [Bun integration record](runtime-validation/2026-09-21-system-defaults-bun.json) contains 36 successful plain/audited sessions. Internal signals use the actual default entry point and wall clock; supplied signals use an injected clock observed exactly once before payload callbacks. All event snapshots and the final assistant message retain the same timestamp. The fixture also checks real preparation, grammar metadata through numeric/null replacement, callback failures, invalid retry options, missing credentials, invalid resolver configuration and malformed SSE. Default diagnostics report only the current SSE block, the caller signal stays live, and channels, parked IO, sockets, timers and fixture file descriptors return to zero. Native execution of this factory remains pending: C generation exceeded both 44 GiB and 49 GiB process guards. The [memory investigation](bend-issues/2026-09-21-system-defaults-memory.json) preserves both failures and the unsuccessful fixture-factoring experiment. This limitation belongs to compilation of this assembly; the underlying provider session has separate successful native validation.

The generic retirement-order law and the full clock-before-initialization law retain their original statements. The current isolated compiler overflows while checking the clock law. An experimental congruence shortcut checks both statements, but has been rejected for adoption because it forces discarded arguments and regresses a total safe proof: the unchanged root gate passes under the candidate, and performance evidence remains limited to three alternating root-proof checks plus an emission comparison with differing background workloads. Clock omission, timestamp discard and reversed cleanup typecheck but are rejected by the unchanged laws under the candidate. These laws are not part of the 502-law root gate and are not claimed as verified by the project's accepted compiler.

This factory still requires configuration and error rendering and uses cleartext transport. Custom fetch selection, TLS, authentication lifecycle and completion of the public provider remain separate work. No upstream test suite status changes with this integration.
