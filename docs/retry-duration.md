# Native retry duration validation

The retry sleep adapter accepts finite binary64 durations in `[0, 2^32)` milliseconds and floors fractional values into the native U32 timer. Signed zero becomes zero. Negative, nonfinite and overflowing values return `timer-delay.InvalidDuration` containing the original binary64 value, before any timer or cancellation observer is created. Invalid input takes precedence over cancellation at this adapter boundary. Ordinary cancelled sleeps still become `RequestAborted`; invalid durations become the distinct `RetryFailure.SleepRejected`.

This replaces the former Node-style one-millisecond fallback for invalid/oversized values. The pinned upstream `packages/ai/src/utils/provider-retry.ts` passes `Math.max(0, ms)` to `setTimeout`; its host timer behavior is deliberately not replicated under the approved strict-input policy. Legitimate fractional jitter remains supported. The existing provider policy may normalize a past server date to zero before reaching this boundary; that policy is unchanged. Native fetch deadlines retain their separate exact-integer conversion contract.

Three generic retry laws preserve invalid-duration causes, classify cancellation and permit continuation after successful sleep. A fourth law establishes that rejected conversion produces a pure error result with no timer effect, for every error and optional signal. These are control-flow and ownership claims, not a universal proof of binary64 flooring. An independent Python binary64 oracle checks 1,225 boundary/random inputs on each of native one/four threads and Bun, including exact rejected-value bit retention. The external-reference invalid-date trace intentionally changes: its NaN delay now terminates with `SleepRejected` and no timer, instead of a one-millisecond retry followed by success. The other eleven real-timer reference traces retain their expected behavior. All five named upstream retry tests pass on native one/four threads, including the early-deadline sensitivity control. Native and Bun smoke checks exercise valid, cancelled and invalid sleeps, including invalid input with an already-aborted signal.

The [full proof gate](proof-validation/2026-09-21-retry-duration.json) passes 412 public laws and 65 supporting lemmas and rejects 225 typed mutations, open obligations and a missing proof. All recorded runtime checks pass. No upstream suite status is promoted by this work. The full native provider and coding-agent port remain unfinished.
