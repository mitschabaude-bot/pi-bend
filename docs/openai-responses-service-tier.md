# Default Responses pricing

`openai-responses-service-tier` ports the pinned provider's service-tier cost adjustment into immutable Bend values. Flex scales all four cost components by 0.5. Priority uses 2.5 for the exact model ID `gpt-5.5` and 2 for other IDs. Other or absent tiers preserve the entire original usage. Adjusted totals use the original left-associated binary64 addition order; token counters and optional token details are unaffected.

Five generic laws cover unchanged usage, preservation of all token counters, absent tiers, model independence of flex pricing, and component/total calculation. The [full proof gate](proof-validation/2026-09-21-service-tier.json) checks 443 public laws and 67 supporting lemmas and rejects 238 well-typed mutations. The [numeric and callback evidence](runtime-validation/2026-09-21-service-tier.json) contains 3,120 comparisons against the actual pinned TypeScript functions across plain/audited native one/four threads and Bun. Every vector creates, calls and disposes a pricing callback. Boundaries include signed zero, subnormals, cancellation, overflow, infinities, NaNs and unchanged stale totals. NaNs are compared by classification; other results by their exact binary64 bits.

`openai-responses-stream-defaults` owns that callback in an affine wrapper and lends a reusable stream-options value. Borrowing retains the requested tier and the supplied grammar mapping and uses the standard tier resolver. Disposal retires only the owned pricing callback. Two generic laws check owner/configuration preservation and the disposal program. These laws pass separately and are not yet registered in the full root. Another [3,120 runtime comparisons](runtime-validation/2026-09-21-stream-defaults.json) exercise pricing through this owner and its borrowed options. All audited channel and IO counters finish at zero.

The default owner is not yet wired into native session creation. The public provider must derive grammar mappings from request preparation, retain the owner through all processing outcomes, and dispose it before session `wait` completes. The full provider, transport selection and authentication lifecycle remain unfinished. No upstream suite status changes follow from these components.
