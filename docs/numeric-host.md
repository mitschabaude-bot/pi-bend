# Numeric host input

`numeric-host.parse` parses an explicitly numeric input into an immutable `Input`: IPv4, or IPv6 with an optional unresolved scope string. It uses the existing strict IP presentation parser, without brackets, ports, whitespace, abbreviated IPv4, octal/hexadecimal IPv4 or leading-zero decimal octets. A zone on IPv4 and an empty IPv6 zone are errors. Other IPv6 zone text is retained verbatim, without percent decoding; a parsed `Input` is not yet a usable scoped socket address.

`selected` filters that parsed value using the existing `Any`, `IPv4Only` and `IPv6Only` family request. It retains the exact address and zone or returns `FamilyMismatch`. It neither maps nor unmaps addresses. `prepare` composes parsing and selection, preserving a parse error instead of replacing it with a family error. `InvalidAddress` retains the original input. This is an explicit numeric-input API: rejecting a hostname here does not decide whether a higher layer should perform DNS lookup.

The pinned [glibc numeric address path](https://raw.githubusercontent.com/bminor/glibc/glibc-2.39/nss/getaddrinfo.c) processes numeric addresses before NSS lookup. It uses legacy `inet_aton` IPv4 syntax and performs additional family/mapped-address handling. The strict parser here follows the user's preference against permissive legacy parsing; it does not claim full `getaddrinfo` equivalence. Mapped-address conversion policy remains separate from this exact-family filter. The reference also treats scope-resolution failure as terminal; the configuration-only resolver's diagnostic-and-scope-zero fallback must not be reused silently for destination connections.

Six generic laws establish unrestricted retention, same-family address/zone retention, rejection of either cross-family input and retention of arbitrary parse errors. They quantify over addresses and scope strings; they do not prove the IP parser itself or assert that a retained scope is valid. Differential cases check strict address parsing against OS `inet_pton`, using an independent scope-split/family oracle. Scoped inputs include interface names, decimal indices, overflow values and additional percent characters specifically to verify verbatim retention; successful parsing does not assert successful interface resolution.

Scope resolution, numeric-first dispatch, mapped-address options, and adoption into the native hostname/HTTP path remain pending. The application has no new numeric fallback/default behavior from this primitive alone.

All 9,504 [executed cases](runtime-validation/2026-09-20-numeric-host.json) pass across native one/four threads and Bun. The [proof gate](proof-validation/2026-09-20-numeric-host.json) checks 152 public laws and 55 supporting lemmas and rejects all 104 typed mutations, including wrong-family acceptance, erased scope text and replaced parse errors. Archived source hashes match. These pure builds and proofs use the installed compiler under the 8 GiB build guard. No compiler/runtime patch or unsafe annotation was added.
