### Bounded octet-level HTTP line reader

`runtime/src/http-line.bend` provides incremental CRLF framing for the future HTTP parser. This is a framing primitive, not an HTTP acceptance policy: bare LF and CR not followed by LF remain payload for a later syntax validator. ### Pure DNS name wire codec

`runtime/src/dns-name.bend` implements binary DNS labels and compressed-name decoding as a dependency of the forthcoming native resolver. `Name` stores octets per label, preserving spelling, case, embedded zeroes and non-text bytes. Encoding produces an uncompressed name and enforces nonempty labels of at most 63 octets and an expanded name of at most 255 octets including the root. Empty label lists represent the root. Hostname/IDNA conversion and case-insensitive question comparison belong to higher layers.

A validated immutable packet index supports offset lookup without repeated list scans. It rejects non-octets and messages over 65,535 bytes. Decoding returns the native name and the next offset in the original wire field, even after following compression. Pointers must target an earlier name segment; their strictly decreasing ceiling rejects forward/self/cyclic references. Expanded labels have the same 255-octet bound. A 65,536-step structural budget exceeds the maximum possible strictly decreasing 14-bit pointer chain plus bounded label bytes. The codec detects reserved label forms, missing bytes and invalid offsets; it does not know the enclosing message's field boundaries or verify that every target was a previously parsed name field.

The implementation follows [RFC 1035 section 2.3.4](https://www.rfc-editor.org/rfc/rfc1035.html#section-2.3.4) and [section 4.1.4](https://www.rfc-editor.org/rfc/rfc1035.html#section-4.1.4). `python3 tests/dns_name_check.py` passes 1,987 cases on native one/four threads and Bun, checked against an independent byte interpreter. Cases include arbitrary binary labels, exact size boundaries, compressed suffixes, pointers to pointers, 8,192-pointer chains, truncation, cycles, all first-octet forms, U32-max offsets, and the message-size limit. The [record](runtime-validation/2026-09-20-dns-name.json) retains source/build hashes and guarded build measurements. No compiler/effect changes were required. DNS message parsing, transaction matching, transport, configuration, caching and provider integration remain implementation work; upstream suite statuses are unchanged.

### Per-request DNS cancellation tickets

Pending registration now returns a `Ticket{id, serial}`; successful session submission exposes that ticket. Each successful registration advances the session-local serial once. ### Owned deadline scope

`runtime/src/deadline.bend` composes the existing owned timer and removable abort observations in pure Bend. The affine scope owns a child abort controller and two joined tasks: parent forwarding and timer expiry. ### Ordered TCP server driver

`dns-tcp-servers.bend` executes a supplied server list in order under a borrowed deadline, preserving duplicate entries. The exact query/ID is reused across the pass. Every exchange closes before a subsequent attempt starts. A reply, including a DNS error code or truncation, returns immediately. Covered network failures can advance; abort, validation, adoption, local-state and cleanup failures stop with the original typed report. An empty list returns `NoServers`, and exhaustion retains the last failed report rather than manufacturing a new error.

The outer TCP pass follows [glibc's transport implementation](https://raw.githubusercontent.com/bminor/glibc/glibc-2.39/resolv/res_send.c): TCP visits the server order once, and response codes are not handled with UDP-style server failover.
