### Bounded octet-level HTTP line reader

`runtime/src/http-line.bend` provides incremental CRLF framing for the future HTTP parser. This is a framing primitive, not an HTTP acceptance policy: bare LF and CR not followed by LF remain payload for a later syntax validator.
