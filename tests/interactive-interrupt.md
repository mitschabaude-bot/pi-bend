The mounted PTY fixture pins pi v0.87.1 `interactive-mode.ts` and `core/keybindings.ts`. It exercises a delayed provider through native1/native4: Enter queues a steering message during an active prompt; Escape restores it to the editor and aborts the request; Alt+Enter queues a follow-up; Alt+Up restores that message without aborting the request; idle Escape leaves the editor alone; double Ctrl+C exits and restores terminal state. The controller lifecycle fixture also passes on Bun.

The native editor uses the existing typed keybindings and a serialized callback to enqueue actions. SessionController owns one joinable prompt task while its dispatcher handles steering, follow-up and interrupt jobs. AgentSession.clearQueue returns the queued text, clears both agent queues, and emits `QueueUpdate` as upstream does. A queued message is restored ahead of the current editor draft, separated by a blank line.

Pending upstream behavior: queued-message rows beneath the editor, bash-mode Escape, double-Escape tree/fork settings, compaction-specific queued input, Ctrl+D exit, and platform-specific WSL/macOS keymap selection. The PTY provider deliberately checks the abort signal only after its delayed response window; this proves no late assistant output appears after Escape, while not measuring the latency of a cancellable network provider.
