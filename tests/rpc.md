# Native RPC protocol, incremental milestone

The endpoint in `packages/coding-agent/src/modes/rpc.bend` accepts already decoded Unicode chunks through `feed(handle, chunk)`, flushes a final unterminated JSON record through `finish(handle)`, and emits newline-terminated JSON records through a caller-owned callback. `start(session, sink)` subscribes to AgentSession events and starts one prompt worker. `stop(owner)` closes its work queue, waits for an accepted prompt to finish, then unsubscribes its listener; the caller may dispose the sink after `stop`. Draining at EOF is an intentional native lifecycle choice; upstream exits its process at EOF.

This milestone handles `prompt`, `steer`, `follow_up`, `abort`, `abort_retry`, `get_messages`, `get_last_assistant_text`, `get_entries` (including `since`), `compact`, `set_session_name`, and `set_thinking_level`. A validated idle `prompt` response is written before its worker starts, so agent events cannot overtake that acknowledgement. A second prompt without `streamingBehavior` while one is active is rejected; `steer` and `followUp` behavior queue into AgentSession. Image blocks are decoded to native `Ai.ImageContent` with strict field types. Unknown commands return a correlated error. Invalid JSON and non-object records return parse errors. The JSON parser's error text is stable and language-independent rather than reproducing the host JavaScript engine's exception prose. A session-event conversion failure is reported on stderr instead of silently dropping it from the JSONL stream.

The protocol fixture covers strict LF and CRLF framing, U+2028/U+2029 inside payloads, an unterminated final record, a record split over chunks, and success/error response ordering. `rpc_protocol_check.py` pins the hashes of pi v0.87.1's `rpc/jsonl.ts` and `rpc/rpc-mode.ts`, calls the actual upstream `attachJsonlLineReader` and `serializeJsonLine`, and compares six byte-exact outputs on Bun, native one thread and native four threads. The faux-provider lifecycle fixture checks prompt ACK before the first event, typed image preservation, strict malformed input, `get_entries`, and drain through `agent_settled` on EOF, on all three backends.

Run `bun build/bend-process-files/bend2/main.ts tests/rpc-protocol.bend -o build/rpc-protocol.js`, `BEND=build/bend-process-files/bend2/main.ts sh scripts/build-pure.sh tests/rpc-protocol.bend build/rpc-protocol-native`, then `python3 tests/rpc_protocol_check.py`. Build `tests/rpc-session.bend` to `build/rpc-session.js` and `build/rpc-session-native` with the same two commands, then run `python3 tests/rpc_session_check.py`. An isolated worktree may set `BEND` to the main checkout's compiler path.

Remaining upstream commands are `clear_queue`, `new_session`, `get_state`, `set_model`, `cycle_model`, `get_available_models`, `cycle_thinking_level`, `get_available_thinking_levels`, `set_steering_mode`, `set_follow_up_mode`, `set_auto_compaction`, `set_auto_retry`, `bash`, `abort_bash`, `get_session_stats`, `export_html`, `switch_session`, `fork`, `clone`, `get_fork_messages`, `get_tree`, and `get_commands`. Native AgentSession currently lacks public APIs for queue clearing/modes, auto settings mutation, bash execution and cancellation, model selection/catalogue, session stats and HTML export, and session replacement; these require additional core/runtime work. `get_tree` needs an iterative serializer in this module because Bend disallows mutually recursive serializers. Extension UI request/response and prompt expansion need native extension/preflight support. Native streaming stdin and strict UTF-8 chunk decoding belong to the caller's transport.
