# Native main-screen renderer

`packages/tui/src/tui-main-screen.bend` ports the render-state and terminal-output decisions from pinned `pi-mono/packages/tui/src/tui-main-screen.ts` at `46c9de402`. The caller prepares a frame by composing overlays, extracting the cursor marker, and applying line resets, then calls `checkedPlan`. The result is a new immutable state and a pull-based stream of ordered `Write` and `Visibility` effects. The caller must drain effects in order and retain the returned state only after applying them.

`python3 tests/tui-main-screen-differential.py` runs the pinned TypeScript renderer and the Bend fixture with the same 26 frames. It compares each terminal write and cursor visibility call, as well as previous line count, dimensions, cursor rows, maximum rendered lines, viewport top, redraw count, and Kitty image ID order. Cases cover first/full/differential renders, appends, changed middle lines, deletion, width/height changes, Termux height changes, clear-on-shrink, changes above the viewport, Kitty reservations and deletion, scroll fallback, and hardware cursor positioning. Set `BEND_COMPILER` if the current compiler is elsewhere and `BEND_MAIN_SCREEN_NATIVE` to a compiled fixture binary to include native output in the comparison.

`tests/tui-main-screen-bounded.bend` checks that output over 1 Mi UTF-16 units is split into exact writes and that an astral scalar at the boundary stays intact. `tests/tui-main-screen-preflight.bend` checks that an overwide differential line returns an error before any effect stream can be applied. In upstream TypeScript the width error is discovered after output has begun; the pure planner intentionally decides this before exposing effects. No compiler/runtime patches or production host-language glue are part of this port.
