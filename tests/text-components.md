# Text and TruncatedText

Source: `pi-mono` revision `46c9de402`, `packages/tui/src/components/{text,truncated-text}.ts` and `packages/tui/test/truncated-text.test.ts`. The reference runner verifies SHA-256 hashes before executing the original nine named tests and recording their render calls. The Bend fixture reproduces those outputs exactly, retaining every original assertion through the reference execution. Supplemental comparisons exercise 816 rendering combinations, cache reuse, invalidation, setter updates and callback ordering, plus long inputs.

`Text.render` returns `IO(Text & List<&2,String>)`: retain the returned immutable state to reuse its cache. `setText`, `setCustomBgFn` and `invalidate` return state with no cached output. Optional background callbacks use the existing native `Callback<String,String>` interface; the caller owns their lifetime and must keep them alive through rendering. Content callbacks run before padding callbacks, and the same computed padding lines occur above and below the content, preserving upstream effects and order. `TruncatedText.render` is pure and `invalidate` returns the unchanged value. Native widths and padding use `Nat`; optional constructor values select upstream defaults.

Approved normalization difference: upstream Text blindly replaces every tab, including tabs inside terminal control payloads. Native Text uses the shared terminal scanner, expanding visible tabs to three spaces while preserving control payload bytes. Three independent OSC/APC cases check that difference. The shared scanner also retains its established Thai/Lao terminal normalization. TruncatedText delegates to the existing native truncation behavior.

The long-input checks exposed eager evaluation in `runtime/text.bend`'s `blank`: `whitespace(code) && blank(rest)` evaluated the recursive suffix even for nonblank text and overflowed the Bun call stack. Selecting a conditional thunk makes the recursion tail-positioned and stops at the first non-whitespace character. This is a project function correction with no compiler change. `tests/text-blank.bend` directly checks 100,000 spaces and nonblank characters at either end on Bun and native one/four threads.

Build both fixtures using the installed compiler (`bun "$BEND" tests/text-components.bend -o build/text-components.js` and `BEND="$BEND" sh scripts/build-pure.sh tests/text-components.bend build/text-components`; substitute `text-blank` for its direct regression). The reference dependencies are test-only `chalk` and `get-east-asian-width`, installed under `build/text-reference/node_modules`. Run `python3 tests/text_components_check.py` for Bun/native one/four; `--prefix` selects isolated output names. Run each `text-blank` binary directly and require `long blank and nonblank checks passed`.

These components are independently usable native modules. This milestone does not claim compositor ownership/lifecycle integration or complete TUI parity.
