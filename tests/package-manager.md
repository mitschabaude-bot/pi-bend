# PackageManager resolution

`core/package-manager.bend` ports upstream `DefaultPackageManager.resolve` for local resources: the skills, prompt templates and themes named by the global and project settings (plain paths searched as upstream's `collectFilesFromPaths` does, with include/`!`exclude/`+`force-include/`-`force-exclude patterns) and those auto-discovered in the project's `.pi` (when trusted), the `.agents/skills` directories from the cwd up to the Git root, the agent directory and `~/.agents/skills`, each enabled unless an override disables it. Entries keep insertion order with the first metadata per path, are stably sorted by precedence (project before user, settings before auto-discovery) and deduplicated by canonical path. Directory listings follow Node's `readdirSync` (byte order), honour `.gitignore`/`.ignore`/`.fdignore` with one matcher shared down each walk, skip dot entries and `node_modules`, and follow symbolic links.

`tests/package_manager_check.py` builds a fixture tree (nested and linked skills, a dangling link, ignore rules, hidden and `node_modules` entries, settings paths including `~`, exact `+`/`-` overrides, minimatch globs and brace patterns (`runtime/minimatch.bend`), project and user prompts and themes, `.agents` directories above and below the Git root) and compares the resolution with `tests/package_manager_reference.ts`, which runs the pinned upstream `DefaultPackageManager` under Bun with a loader plugin that sorts `readdirSync` as Node does. All 24 resolved resources match on Bun and native one/four threads.

Build: `bun build/bend-native-toolchain/bend2/main.ts tests/package-manager.bend -o build/package-manager.js`, `BEND_TUS=4 sh scripts/build-pure.sh tests/package-manager.bend build/package-manager`, then `python3 tests/package_manager_check.py [--runner build/package-manager --threads N]`.

Not ported: package sources (settings `packages`: npm, git and local package directories, their manifests and filters), and extensions.
